# POR Interactive

p5.js hero graphic for the Plan of Record landing page (1440 x 900).

## Run
Open `index.html` with the VS Code **Live Server** extension.

## Fonts
Put `SEASRN__.ttf` in this folder (same level as `index.html`).
Font source: https://www.fontspace.com/contender-version-font-f53852
Check the font license before pushing it to a public repo.
